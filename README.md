# Keep on Keeping on · 工具封装

一个独立的 SillyTavern 前端扩展。它在本轮请求里把用户原文放进工具结果，也能要求模型用函数提交答复，最后只把提取的正文交给酒馆。两个功能可单独开启。不需要 MMDB-PG、酒馆助手、额外后端或新的 API 密钥。

## 安装与使用

1. 将安装包解压到酒馆的 `data/<用户目录>/extensions/`，让文件位于 `extensions/SillyTavern-Keep-on-Keeping-on/manifest.json`。默认用户目录通常是 `default-user`。也可直接把本项目文件夹复制到同一位置。
2. 刷新酒馆，在「扩展」面板中展开 **Keep on Keeping on · 工具封装**。
3. 按需勾选 **把本轮输入放进工具结果** 和 **用工具提交并提取回复正文**。首次安装时两项均关闭，升级会沿用已有开关。使用「严格」预设时，正常发一条消息，然后看面板的「最近请求」。例如显示 **已封装 3 条输入消息（strict_tools）**，表示本轮采用了酒馆保留工具的严格模式。原预设无需修改。
4. 输出默认允许模型自动选择。若需要每条回复都通过函数提交，可勾选 **强制模型调用正文工具**。面板会区分「已提取工具正文」和「模型直接返回正文」。

## 一轮请求如何处理

例如用户发送「写一段雨夜的对话」，两项都开启时：

1. 扩展按当前提示词后处理找到最后一个用户回合。「严格」和「半严格」会把尾部连续的用户消息和中途插入的系统消息合成一个回合。例如时间线、玩家发言、格式要求会依次出现在同一个工具结果里。开头连续的系统提示保留在系统区。「合并」只合并相邻用户消息，未启用后处理时取最后一条用户消息。
2. 扩展在原处保留输入引用和媒体，本地生成 `kok_read_input` 调用，工具结果包含与调用一致的 `request_id` 和保存整段原文的 `input`。输出协议放在开头系统区的末尾，交付提醒放在输入引用中，模型最后读到工具结果。若有助手预填，读取记录接在预填之后；同时开启输出封装时，最后追加交付提醒。单次合成读取只需一次模型请求。
3. 模型调用 `kok_emit_answer` 时，扩展校验工具名、数量和参数，将唯一字符串 `content` 交给酒馆，保留换行、标签和 Markdown。自动模式也接受正常结束且只含普通正文的回复。工具调用与普通正文混杂、参数残缺或达到输出上限时会报错。

只开输入时，酒馆沿用原来的流式设置。开启自动输出时，OpenAI 兼容连接向上游取完整 JSON，按酒馆选择返回普通响应或流式事件。原生 Gemini 通过事件流取得结束原因。开启输出封装后，正文都是校验完一次显示。

## 连接与适用范围

- 适用于聊天补全的 **OpenAI、自定义 OpenAI 兼容、OpenRouter、Google AI Studio（Gemini）、Vertex AI（Gemini）** 连接。接口需要支持函数工具，强制模式还需要支持指定函数。自定义连接选用 MMDB 的 `pg-…-抗截断` 模型时由 MMDB 处理，保留它的原生续写能力。
- 处理普通聊天、重新生成、滑动生成单个候选、继续和代写。静默／后台请求、文本补全、其他连接、已有工具声明或工具历史、结构化输出、多候选、搜索和生图请求按酒馆原样发送。
- 继续生成时向前找到最近一个用户回合，按同样顺序封装。选用「单条消息」后处理时，输入封装会跳过，原因显示在面板。如果同时装有工具辞典，它已标记接管的请求由它处理。单独测试本扩展时请关闭工具辞典的输入和输出。
- 输出封装仅传递完整答复，不提升模型输出上限，不自动续写。原生 Gemini 在输出封装下用流式上游取得结束原因，再转换回酒馆当前需要的格式。

## 验证与参考

无需安装依赖，Node.js 22 下运行 `npm test`。测试覆盖输入配对与隔离、多模态、各开关组合、JSON/SSE 正文提取、错误、截断及取消。可选验收服务：运行 `node tests/local-provider.mjs`，把测试酒馆的自定义连接地址设为 `http://127.0.0.1:18745/v1`，开启两项并发送「封装验收」。服务只监听本机，成功时回复两段固定中文。

1.1.0 使用 **SillyTavern 1.19.0（06bde939f）** 的实际后处理函数，对比了严格、半严格、合并和无后处理共 16 个组合。通过 MMDB-PG 的 OpenAI 转换函数和酒馆的 Gemini 转换函数核对了工具结果原文。输出测试采用模拟响应，未测量真实模型的文风或成功率。

合成读取和正文工具参考 MMDB-PG 的 `src/server/input-read.mjs` 和 `src/server/anti-truncation.mjs`。1.1.0 的严格后处理适配、工具结果原文和自动交付方式参考《ホームの先の編舟者 · 工具辞典》3.2.1。扩展目录约定见 [SillyTavern 官方文档](https://docs.sillytavern.app/for-contributors/writing-extensions/#manifestjson)。
